# BiomedCLIP experiment outputs

- `figures/`: high-resolution experiment plots.
- `selected_xrays/`: copies of the selected X-rays used in this run.
- `tables/`: CSV similarity scores, summaries, and prompt comparisons.
- `concept_prompts.json`: concept prompt definitions.
- `run_metadata.json`: model and experiment configuration.

Cosine similarity and softmax-over-concepts values are relative similarity measures,
not calibrated probabilities or clinical diagnoses. The full CheXpert dataset is not copied here.
